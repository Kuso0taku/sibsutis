# Debug C 

- GNU Debugger (GDB)
- Unit-tests
- logs (stderr or FILE)
- makefile (obviously) with maybe test or dedbug labels

## Grade "Satisfactory"
- compile with `-g` flag (for GDB)
- set pointers on `malloc`, `free`, others
- check addresses before and after 
- make sure memory frees correctly

## Grade "Good"
- choose part of the code with loop
- compile with `-O{1,2,3}`

## Grade "Excellent"
- learn `Valgrind (Memcheck)`, `strace`, `ltrace`
